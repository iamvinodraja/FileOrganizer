# Ultimate File Organizer (macOS / Windows)

A powerful, modern, and intelligent File Organizer with:

✔ Dark/Light Themes  
✔ Drag & Drop Folder Selection  
✔ Multi-Folder Support  
✔ Auto-Watcher (Automatic organizing)  
✔ Password Protection  
✔ Dropbox Backup (optional)  
✔ AI Categorizer (optional – scikit-learn)  
✔ Progress Bar, Logs, Notifications  
✔ macOS DMG / Windows EXE Packaging Support
